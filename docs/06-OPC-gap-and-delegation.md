## 你必须本人完成或明确授权的项目

| 事项 | 为什么必须你参与 | 最小操作 |
|---|---|---|
| GitHub 账号及私有仓库 | 外部账户和所有权归你 | 注册/登录，创建 Private repo |
| OpenAI API 项目与付费 | 需你同意费用和条款 | 创建 API Key，设置账单提醒和权限 |
| GitHub Secret 录入 | 密钥应由你输入，不能通过聊天发送 | `OPENAI_API_KEY` 添加到 Settings |
| 第一次云端工作流验收 | 需要真实云端运行记录 | Actions 手动运行并查看结果 |
| 实际玩家招募和授权 | 涉及真实测试人员与隐私 | 首批至少 15 人用户测试 |
| IP 许可与作品确权 | 法律和公司权利主体的决策 | 明确七灵素材归属并登记 |
| 游戏发行账户和收款 | 真实身份、税务和金融资料 | 后期进行，当前不需 |
| VPS 与持久在线 AI 执行器 | 要花钱并管理公网安全 | 等 Actions 验证后再批准部署 |

## 最值得做的下一步

**先接通 GitHub 仓库并完成首轮云端验证**。成功标准：仓库可见工程、质量测试通过、日报运行、Codex 候选代码生成且安全门禁通过、生成待审核 PR（如有合法非空改动）。这比马上购买服务器有更高的验证价值。

## 决策边界

- 自动化可以**每天尝试**执行任务，但不能保证每次成功或连续 24 小时 AI 在工作。
- AI 可以自主写候选代码，但不会在没有权限与审批的情况下部署正式游戏、支付、宣传购买素材或授予 IP 使用许可。
- 真实盈利须在产品上架且有真实销售及成本数据后才能报告；当前不作盈利承诺。

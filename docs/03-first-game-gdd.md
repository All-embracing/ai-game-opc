# 《七灵·心隅花园》玩法设计文档（验证稿）

## 电梯介绍

每次把一组同色情绪光点整理好，就获得一点能量；能量让花园长出一朵花。三位精灵提供轻微不同的策略。目标是在第一次 90 秒试玩中，让人体验到“轻松消除→分数奖励→花园变化”的正向循环。

## 目标用户和边界

先面向喜欢轻策略解谜及治愈视觉的成年独立游戏玩家。不做医疗功效承诺，也不宣传游戏能治疗睡眠障碍、焦虑或其他心理问题。

## 当前可玩的 V0.1

- 棋盘 6×6 四色，点击相邻同色组至少 2 个消除，剩余元素下落并补齐。
- 关卡目标 360 + 180 × (阶段-1)，基础步数 18。
- 晴光灵得分加 10%；雀跃灵消除 5 格或以上加 75；酣眠灵起始额外 +2 步。
- 每过关种一朵花，自动保存阶段和花数到本地浏览器。
- 没有真钱、账号、广告、在线分析或正式素材。

## 玩法研究要回答的问题

1. 30 秒内不读说明能否完成首次有效操作？
2. 大团块消除是否带来策略乐趣，而不只靠随机运气？
3. 三位精灵选择能否形成可理解的玩法差异？
4. “种花”能否带来第二局的自然动机？
5. 只有此机制是否过于简单，怎样引入新奇目标而非数值膨胀？

## 演进方向

- 核心循环验证后，设计真正情绪叙事、花园装饰系统、探索阶段以及高完成度 UI 和音效。
- 引导、提示、撤销、键盘/无障碍、可控随机数和可重复测试。
- 正式游戏将迁至 Godot 4.7 稳定分支或其他经过实际导出测试的引擎；网页版仅用于低成本验证。
- 权属明确后再接入最终版七灵原稿，确保遵守四肢无尾巴等角色规范。
